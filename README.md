# NeuroAI - Современная нейросеть на базе OpenRouter

![NeuroAI](https://img.shields.io/badge/NeuroAI-OpenRouter-blue)
![Node.js](https://img.shields.io/badge/Node.js-18+-green)
![License](https://img.shields.io/badge/License-ISC-lightgrey)

**NeuroAI** — это современная, минималистичная платформа для работы с нейросетями через OpenRouter API. Красивый дизайн, плавные анимации и расширенная функциональность.

## ✨ Основные возможности

### 🎨 Дизайн
- **Минималистичный современный интерфейс** — чистый и понятный дизайн
- **Плавные анимации** — все переходы и эффекты плавные и естественные
- **Адаптивность** — отлично работает на всех устройствах
- **Тёмная тема** — комфортная для глаз в любое время суток
- **Градиентные эффекты** — красивые анимированные градиенты

### 💬 Чат
- **Интерактивный чат** — общение с нейросетью в реальном времени
- **История диалогов** — сохранение истории в localStorage
- **Поддержка нескольких моделей** — выбор из лучших моделей OpenRouter
- **Настройка параметров** — креативность и максимальное количество токенов
- **Типинг-индикатор** — визуальная обратная связь при генерации

### 🖼️ Генерация изображений
- **Режим генерации изображений** — переключение между текстом и изображениями
- **Поддержка Stable Diffusion** — качественная генерация изображений
- **Отображение результатов** — красивое отображение сгенерированных изображений

### 📊 Статистика
- **Счетчик сообщений** — количество отправленных сообщений
- **Счетчик токенов** — общее количество использованных токенов
- **Счетчик запросов** — количество выполненных запросов
- **Сохранение статистики** — данные сохраняются в localStorage

### 🛠️ Технические возможности
- **Node.js + Express** — надежный бэкенд
- **OpenRouter API** — доступ к лучшим AI-моделям
- **CORS поддержка** — безопасное взаимодействие с фронтендом
- **Логирование** — отслеживание всех запросов
- **Обработка ошибок** — понятные сообщения об ошибках

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка API ключа
Создайте файл `.env` в корне проекта:
```env
OPENROUTER_API_KEY=ваш_api_ключ
```

Получить API ключ можно на [OpenRouter](https://openrouter.ai/keys).

### 3. Запуск сервера
```bash
npm start
```

Сервер запустится на `http://localhost:3000`.

### 4. Открытие интерфейса
Откройте файл `index.html` в браузере или используйте локальный сервер.

## 🔧 API Эндпоинты

### POST /api/chat
Чат с историей диалогов.

**Тело запроса:**
```json
{
  "messages": [
    {"role": "system", "content": "Ты полезный ассистент..."},
    {"role": "user", "content": "Привет!"}
  ],
  "model": "mistralai/mistral-small-creative",
  "temperature": 0.7,
  "max_tokens": 500
}
```

### POST /api/generate
Генерация текста или изображений.

**Тело запроса:**
```json
{
  "type": "text" | "image",
  "prompt": "Ваш запрос",
  "model": "mistralai/mistral-small-creative",
  "temperature": 0.7,
  "maxTokens": 500
}
```

### GET /api/models
Список доступных моделей.

### GET /health
Проверка состояния сервера.

## 🐛 Отладка

### Проблемы с запуском
```bash
# Проверьте зависимости

```

### Проблемы с API
- Проверьте наличие `.env` файла

- Проверьте баланс на OpenRouter

### Проблемы с интерфейсом
- Откройте консоль браузера (F12)
- Проверьте сетевые запросы
