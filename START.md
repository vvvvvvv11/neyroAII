# 🚀 Запуск NeuroAI

## Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера
```bash
npm start
```

Сервер запустится на `http://localhost:3000`.

### 3. Открытие интерфейса
Откройте файл `index.html` в браузере.

## 🎮 Как использовать

### Режим чата
1. Выберите модель из списка
2. Настройте креативность (0-2)
3. Установите максимальное количество токенов (100-2000)
4. Введите сообщение и нажмите "Отправить"

### Режим генерации изображений
1. Нажмите на кнопку с иконкой изображения
2. Введите описание для генерации
3. Нажмите "Отправить"
4. Дождитесь результата

### Управление историей
- **Очистить чат** — удалить всю историю
- **Сохранение** — история сохраняется автоматически
- **Восстановление** — при перезагрузке страницы

## 🐛 Отладка

### Проблемы с запуском
```bash
# Проверьте зависимости
npm list

# Переустановите пакеты
npm install
```

### Проблемы с API
- Проверьте наличие `.env` файла
- Убедитесь, что API ключ валиден
- Проверьте баланс на OpenRouter

### Проблемы с интерфейсом
- Откройте консоль браузера (F12)
- Проверьте сетевые запросы
- Очистите кэш браузера
